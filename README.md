# SwiftParker Manager

SwiftParker Manager is a comprehensive parking management system consisting of two main applications:

## Mobile App

The mobile app is built using React Native and Expo, providing a seamless experience for managing parking operations on mobile devices. It integrates Firebase for backend services, supports Google Sign-In, and includes features like barcode scanning and camera functionalities.

### Running the Mobile App

1. Navigate to the mobile app directory:
```
cd mobileapp/SwiftParker_manager
```
2. Install dependencies:
```
npm install
```
3. Start the Expo development server:
```
npm start
```
4. Use the Expo Go app on your mobile device to scan the QR code and run the app, or run on Android/iOS simulators using:
```
npm run android
npm run ios
```

## Manager Web App

The manager web app is a React-based single-page application for managing parking operations, user accounts, and payment processing.

### Running the Manager Web App

1. Navigate to the manager web app directory:
```
cd webapp/manager_webapp
```
2. Install dependencies:
```
npm install
```
3. Start the development server:
```
npm start
```
4. Access the app at [http://localhost:3000](http://localhost:3000) in your web browser.

## Prerequisites

- Node.js and npm installed on your system.
