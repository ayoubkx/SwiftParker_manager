# SwiftParker Manager

First, make sure you have [**Node**](https://nodejs.org/en/download) installed in your system.

## Web application
To run the Web Manager App, enter the manager_webapp repos. If you are in the original one, open the terminal and un:
```
cd webapp
cd manager_webapp
```
After, run:
```
npm install
```
You can now start the app by running:
```
npm run start
```
This will run the app on your system's server, go on http://localhost:3000/
