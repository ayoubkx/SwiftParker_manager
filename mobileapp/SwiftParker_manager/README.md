# SwiftParker Manager Mobile App

This is the mobile application for SwiftParker Manager, built using React Native and Expo. The app provides a seamless and efficient way to manage parking operations on mobile devices.

## Features

- Built with Expo and React Native for cross-platform mobile development.
- Integration with Firebase for backend services including authentication and data storage.
- Google Sign-In support for easy and secure user authentication.
- Barcode scanning and camera functionalities for quick and accurate data capture.
- Utilizes various Expo modules such as Camera, Barcode Scanner, and Device APIs.
- Async storage for local data persistence.
- Navigation handled with React Navigation.

## Getting Started

### Prerequisites

- Node.js and npm installed
- Expo CLI installed globally (`npm install -g expo-cli`)
- Android Studio or Xcode for running on emulators or physical devices

### Installation

1. Clone the repository.
2. Navigate to the `mobileapp/SwiftParker_manager` directory.
3. Run `npm install` to install dependencies.
4. Start the Expo development server with `npm start` or `expo start`.

### Running the App

- Use Expo Go app on your mobile device to scan the QR code and run the app.
- Alternatively, run on Android or iOS simulators using `npm run android` or `npm run ios`.
