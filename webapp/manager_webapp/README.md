# SwiftParker Manager Web App

This is the manager web application for SwiftParker, built using React and React Router. It provides a user-friendly interface for managing parking operations, user accounts, and payment processing.

## Features

- Single-page application built with React and React Router.
- Integration with Stripe for secure payment processing.
- Enhanced UI components using React Icons and React Phone Number Input.
- Responsive design with Tailwind CSS.
- Comprehensive scripts for development, testing, and production builds.
- Authentication and authorization features for user management.

## Getting Started

### Prerequisites

- Node.js and npm installed on your machine.

### Installation

1. Clone the repository.
2. Navigate to the `webapp/manager_webapp` directory.
3. Run `npm install` to install all dependencies.
4. Start the development server using `npm start`.

### Running the App

- Access the app at [http://localhost:3000](http://localhost:3000) in your web browser.
- Use `npm run build` to create an optimized production build in the `build` folder.
